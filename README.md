# Todo List

A simple Todo List application developed using Python.

## Features

- Add new tasks
- View all tasks
- Update tasks
- Delete tasks
- Mark tasks as completed

## Technologies Used

- Python
- Django
- HTML
- CSS
- JavaScript

## Project Description

This Todo List application helps users manage their daily tasks easily.
Users can add, view, update, complete, and delete their tasks.

## How to Run

1. Clone the repository
2. Create a virtual environment
3. Install required dependencies
4. Run the Django server

```bash
python manage.py runserver
